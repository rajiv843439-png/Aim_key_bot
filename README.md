# Telegram Referral Key Bot

## Features
- Personal referral links (`/referral`)
- One key for every 3 unique first-time referrals
- Keys saved to Firebase Realtime Database
- Referral leaderboard, personal stats, key list
- Admin panel, broadcast, stats, manual key generation, pause/resume setting
- Render worker deployment

## Render environment variables
- `BOT_TOKEN`: token from BotFather
- `ADMIN_IDS`: your numeric Telegram user ID (comma-separated for multiple admins)
- `FIREBASE_DB_URL`: `https://kanav-3c195-default-rtdb.firebaseio.com`
- `FIREBASE_AUTH_TOKEN`: optional Firebase ID token/database auth token if your rules require it
- `REFERRALS_PER_KEY`: `3`

IMPORTANT:
- Do not put Telegram bot tokens, Firebase credentials, or secrets inside source code or GitHub.
- The Firebase string described as an API key is not automatically permission to write to Realtime Database. Secure your database rules and use proper authentication.
- The Firebase API-like secret pasted in chat should be considered exposed. Rotate/revoke it if it is a real secret, and only store replacement credentials in Render Environment.
- This bot writes to `/referral_key_bot/...` and does not delete existing Firebase data.
- Keys are randomly generated by this bot and recorded in Firebase. If your key format must match an existing key service/schema, adjust the key-generation logic and database path first.
- Referral attribution is recorded when a new user starts using `?start=ref_<telegram_id>`. Telegram cannot verify whether the invitee is a real human; add anti-abuse checks before distributing valuable keys.
